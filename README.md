# JointCraft 3D 0.2.2

Экспериментальное расширение Blender 5.2+ для создания цилиндрического шипа
и отверстия между двумя соприкасающимися деталями. Проверено в Blender 5.2.0 LTS.

## Подбор размеров с предпросмотром (0.2.2)

1. Назначьте два соприкасающихся объекта в панели JointCraft.
2. Включите **Show live preview**. На месте контакта появятся контуры сквозь
   поверхности: голубой — шип (включая часть внутри первой детали),
   оранжевый — будущее отверстие с учётом зазора.
3. Снимите **Automatic dimensions**, чтобы редактировать **Pin diameter (mm)**
   и **Pin length (mm)**. Контуры меняются сразу при изменении размеров,
   зазора, стенки, объектов и их трансформаций. Диаметр 8 мм и длина 6 мм
   остаются исходными ручными значениями; в автоматическом режиме действуют
   прежние ограничения размера.
4. Для проверки на кубах 20 мм попробуйте диаметр 8 → 14 мм, длину 6 → 12 мм.
   При слишком большом размере предпросмотр скрывается и панель показывает
   максимальные допустимые размеры. Вручную заданные размеры не уменьшаются молча.
5. Нажмите **Create Pin + Socket**, когда результат устраивает. До этого сетки
   не меняются: предпросмотр рисует только вспомогательные линии во Viewport,
   не создаёт объектов и не выполняет Boolean. После создания линии выключаются.

Это схема соединения сквозь модели, а не предварительное вырезание отверстия.
Она не попадает в рендер/экспорт и не подтверждает пригодность произвольной
геометрии к печати. Выключить её можно кнопкой **Show live preview**.

Размеры для схемы и итоговых Boolean рассчитывает одна функция
`joint_parameters()`. Модуль `jointcraft/preview.py` рисует их через GPU draw
handler Blender; при отключении аддона обработчик удаляется.

## Установка и проверка

Установите ZIP через Preferences → Get Extensions → Install from Disk.
Репозиторий расширений: https://marykaweb.github.io/JointCraft-3D/

1. В новой сцене оставьте стандартный Cube размером 2 × 2 × 2 м в (0, 0, 0).
2. Создайте второй такой же куб в (2, 0, 0), Scale = (1, 1, 1).
3. В Object Mode откройте N → JointCraft. Укажите первый куб в Pin object,
   второй — в Socket object. Нажмите Create Auto Pin + Socket.
4. Ожидается сообщение: диаметр 8 мм, длина 6 мм. Отодвиньте второй куб,
   чтобы увидеть соединение. На кубе 2 м шип очень маленький: приблизьте
   область исходного контакта (1, 0, 0). Радиус отверстия больше радиуса шипа
   на 0,20 мм, глубина — на 0,20 мм.
5. Для более удобной визуальной проверки используйте кубы 20 мм с центрами
   (0, 0, 0) и (0.02, 0, 0) при Unit Scale = 1. Размер соединения останется тем же.
   Ctrl+Z отменяет создание соединения.

Поддерживаются закрытые прямоугольные детали с гранями вдоль мировых осей,
включая перенос, масштаб и повороты, сохраняющие такое выравнивание.
Произвольно повёрнутые/скульптурные детали, несколько соединений и шарниры
пока не поддерживаются. Контакт и запас стенок оцениваются по bounding box;
это не полноценная проверка поверхности и пригодности к печати.
Перед созданием соединения сначала примените модификаторы и разрешите shape keys.

## Что исправлено

В v0.2 формула пересечения границ для стандартных кубов верна. В Blender 5.2.0
ошибка `No touching axis-aligned faces found` воспроизведена после изменения
`Location` через Python без обновления сцены: `matrix_world` ещё содержит старую
матрицу. После `view_layer.update()` те же кубы успешно соединяются.
Это подтверждённый сценарий ошибки; без исходного .blend нельзя утверждать,
что прежний сбой через панель был вызван именно им.

В 0.2.1 перед поиском обновляется view layer, используются evaluated-границы,
проверяется принадлежность объектов активной сцене и view layer. Ошибка контакта
теперь содержит имена объектов, мировые границы и допуск в BU/мм.
Допуск имеет небольшой нижний предел для точности float32; он не меняет зазор посадки.
Исправлены нормали цилиндров для направлений -X, +Y, -Z. Обе Boolean-операции
рассчитываются до замены исходной геометрии: ошибка второго расчёта сохраняет
обе детали. Отдельно используемые копии исходного mesh datablock сохраняются.

## Структура

- `jointcraft/__init__.py`: регистрация, панель, проверка объектов, работа с bpy,
  создание цилиндров и Boolean-операции.
- `jointcraft/geometry.py`: расчёт контакта AABB без зависимости от Blender.
- `jointcraft/preview.py`: цветные контуры соединения во Viewport.
- `jointcraft/blender_manifest.toml`: метаданные расширения 0.2.2.
- `tests/`: тесты геометрии, интеграция с Blender и визуальный пример.
- `.github/workflows/release.yml`: тесты, проверка, сборка ZIP, генерация индекса
  расширений и публикация GitHub Pages. Папка сборки `jointcraft` сохранена.

## Автоматизированные проверки

Геометрия без Blender (стандартная библиотека Python):

```sh
python -m unittest discover -s tests -p test_geometry.py
```

Интеграция, включая геометрические тесты:

```sh
blender --background --factory-startup --python-exit-code 1 --python tests/blender_integration.py
```

16 тестов проверяют шесть направлений, числовой допуск, касание ребром/вершиной,
разные размеры, обновление Location, применённые и неприменённые трансформации,
отрицательный масштаб, единицы измерения, объекты вне сцены, пустую геометрию,
нормали и замкнутость сеток, объёмы шипа/отверстия и откат при сбое второго Boolean,
ручные размеры, совпадение контуров с результатом и отказ при слишком большом размере.
Сообщения `Error` в успешном прогоне ожидаемы: это проверки отказа.

GPU-проверка на Windows открывает отдельное скрытое окно Blender с factory settings,
проверяет отрисовку при диаметрах 8 и 14 мм, выключение предпросмотра и удаление
обработчика, сохраняет скриншоты в `artifacts`, затем закрывает окно:

```sh
blender --background --factory-startup --python-exit-code 1 --python tests/preview_smoke.py
```

Визуальный пример (новая изолированная сцена, файлы в `artifacts/`):

```sh
blender --background --factory-startup --python-exit-code 1 --python tests/create_visual_demo.py
```

Проверка и сборка расширения:

```sh
blender --background --factory-startup --command extension validate jointcraft
blender --background --factory-startup --command extension build --source-dir jointcraft --output-dir artifacts
blender --background --factory-startup --command extension server-generate --repo-dir artifacts
```

Перед сборкой создайте папку `artifacts`. CI собирает в `public` и публикует индекс
тем же способом, что и v0.2. Локальная проверка не публикует изменения на GitHub.
